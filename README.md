## 🌦️ SkyFrame

### 🎯 Цель проекта

**SkyFrame** — это расширенная версия проекта [AiFrame от AlexGyver](https://github.com/AlexGyver/AiFrame), дополненная функцией автоматического учета текущей погоды при генерации изображений.

Проект решает задачу **динамического и атмосферного отображения изображений**, которые соответствуют реальным погодным условиям.
Например, если за окном снег — рамка покажет зимний пейзаж, если солнечно — теплый летний пейзаж.

---

### ⚙️ Краткое описание функционала

* Получение актуальных погодных данных через **Open-Meteo API**.
* Автоматическое обновление информации о погоде с заданным интервалом.
* Формирование запроса к нейросети для генерации изображения с учетом:

  * температуры,
  * осадков,
  * облачности,
  * времени суток.
* Отображение сгенерированных изображений на экране устройства (рамки).
* Гибкая настройка параметров: частота обновления, стиль, регион и т.д.

### 🔍 Аналогичные проекты

* [AiFrame (оригинал)](https://github.com/AlexGyver/AiFrame) — базовый проект для генерации и отображения AI-картинок.
* [MagicMirror](https://github.com/MagicMirrorOrg/MagicMirror) — умное зеркало с модулями погоды и новостей.
* [AI Art Frame](https://github.com/feiticeir0/ai-art-frame) — цифровая рамка для генерации картин нейросетью.
* [WeatherPix](https://www.yeschat.ai/es/gpts-ZxX7dtvo-WeatherPix) — визуализация погоды через изображения.

### 🛠️ Планы развития

* Добавление нескольких источников погодных данных (например, OpenWeatherMap).
